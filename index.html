Good to know

Is it really free? Do the codes expire?

Yes, free — no account, no watermark, no limits. The codes are static, meaning the link is baked straight into the pattern. They never expire and will keep working forever, with no reliance on this site.

The trade-off: because the link is fixed, you can’t edit where a static code points after you’ve printed it. If you need that, you’d want a “dynamic” code from a paid service.

What does “error correction” mean?

QR codes carry spare data so they still scan when part of the code is dirty, scratched, or covered by a logo. Higher levels fix more damage but make the pattern denser.

Medium is a sensible default. Go High if the code will be printed small, on fabric, or placed somewhere it might get scuffed.

PNG or SVG — which should I download?

Use PNG for screens, documents, and most prints — pick a larger size if it’ll be printed big. Use SVG for professional print or signage: it’s a vector, so it stays razor-sharp at any size, from a business card to a billboard.

Will my code still scan if I change the colours?

Usually, as long as there’s strong contrast between the two colours and the background is the lighter of the pair. Many scanners struggle with inverted (light-on-dark) codes, so this tool warns you when the contrast looks risky. When in doubt, test it with your phone before printing.

How do I make a Wi-Fi QR code?

Switch to the Wi-Fi tab, enter your network name and password, and pick the security type (almost always WPA). Anyone who scans it is prompted to join — handy for guests and cafés, so nobody has to type a long password.

Is any of this stored or tracked?

No. Every code is generated locally in your browser using JavaScript — the text, links, and Wi-Fi passwords you enter are never sent to a server. Close the tab and it’s gone.
